# 智能待办 · 桌面级待办事项应用

一款**免安装**的桌面级待办事项应用：**灵动岛悬浮窗**、**系统托盘后台常驻**、**按提醒风格自动安排提醒频率**。

> 本仓库为**源码仓库**（不含 66MB 的便携 exe，构建产物已在 `.gitignore` 中排除）。
> 想直接使用，请按下文自行构建，或从本项目的 Releases 下载。

## 快速开始

```bash
npm install
npm start          # 运行开发版

npm run dist       # 打包免安装便携版
# 产物：dist/智能待办-便携版-1.0.0.exe（单文件，双击即用）
```

双击 exe 后：屏幕右下角出现**灵动岛悬浮窗**，托盘出现应用图标，任务到期时以**应用内弹窗 + 灵动岛**提醒，关闭窗口的行为由「设置 → 退出操作」决定。

> **打包常见问题**
> - 下载 Electron / 打包组件失败：仓库内 `.npmrc` 已配置国内镜像。
> - 代码签名组件下载超时：设 `CSC_IDENTITY_AUTO_DISCOVERY=false`。
> - 仓库位于 OneDrive 等同步目录时，解压阶段可能因文件被占用失败，把输出目录指到同步目录之外：
>   `npm run dist -- --config.directories.output=D:\todo-dist`
> - 偶尔出现 `Access is denied`（安全软件拦截新写的文件）：重试一次通常即可。

## 提醒风格

侧边栏顶部的「提醒风格」卡片点开进入**专属覆盖界面**，用生活化语言描述每种风格，并用时间线展示提醒节点：

| 风格 | 适用心态 | 提醒次数 | 提醒时间点（相对截止） |
|------|---------|---------|----------------------|
| 拖延者 · 需要被催 | 我总拖着不动，请多提醒我几次 | 4 次 | 3 天前 / 1 天前 / 12 小时前 / 2 小时前 |
| 忙碌者 · 别烦我 | 我很忙，只在关键节点提醒我 | 2 次 | 1 天前 / 2 小时前 |
| 组织者 · 心里有数 | 我自己会安排，提醒一次就够 | 1 次 | 6 小时前 |
| 完美主义者 · 不能出错 | 我要提前很久就收到分阶段提醒 | 5 次 | 7 天前 / 3 天前 / 1 天前 / 6 小时前 / 1 小时前 |

进入方式：侧边栏「提醒风格」卡片，或 设置 → 提醒风格 → 更改风格。

## 任务视图范围

五个视图互不重叠（都只看未完成任务）；鼠标悬停在侧边栏视图名上也会显示范围提示：

| 视图 | 范围 |
|------|------|
| 全部任务 | 所有任务 |
| 今日到期 | 今天 00:00 ~ 今天 24:00 到期 |
| 即将到期 | 明天 00:00 起，至今天起第 7 天 00:00 之前（**不含今天**） |
| 已逾期 | 截止时间在今天 00:00 之前 |
| 已完成 | 已勾选完成 |

「今日到期」+「即将到期」正好是「今天起的 7 天」。

## 退出操作

设置 → **退出操作**，三段式直接选择，**选中即生效、无需保存**，重启后保持：

| 选项 | 点关闭按钮时 |
|------|------------|
| 每次询问 | 弹出「后台常驻 / 彻底退出 / 取消」选择框 |
| 后台常驻 | 窗口隐藏，程序在系统托盘中继续运行并按时提醒 |
| 彻底退出 | 结束程序进程，不再接收提醒 |

选「每次询问」时，对话框里也会提示可到设置中改为直接执行。设置面板只对**「提醒提前量 / 声音提示」**做未保存跟踪，未保存就关闭会询问「保存 / 放弃更改 / 取消」。

## 灵动岛悬浮窗

**默认开启**，首次启动出现在屏幕右下角；可用操作栏「悬浮窗」按钮或托盘菜单开关，开关状态会被记住。

### 胶囊状态

折叠态为药丸胶囊，图标与配色随状态变化，一行显示最要紧的信息：

| 状态 | 触发条件 | 胶囊显示 | 图标 / 配色 |
|------|---------|---------|------------|
| 逾期 | 有已过截止时间的未完成任务（**含今天已过点的**） | 「逾期 N 项」+ 最急任务名 · 超时 2 小时 | 感叹号 / 红 |
| 即将到期 | 最近一条在 2 小时内到期 | 「即将到期」+ 任务名 · 还有 30 分钟 | 时钟 / 琥珀 |
| 今日到期 | 今天还有未到期任务 | 「今日 N 项」+ 任务名 · 23:30 | 清单 / 主题色 |
| 今日无到期 | 今天没有，但有更晚的任务 | 「今日无到期」+ 明天 9:00 · 任务名 | 清单 / 灰 |
| 全部完成 | 有任务且都已完成 | 「已全部完成」+ 共 N 项 | 对勾 / 绿 |
| 无任务 | 一条任务都没有 | 「暂无任务」 | 清单 / 灰 |
| 提醒中 | 收到提醒后的 5 秒内 | 提醒标题 + 有任务提醒 | 铃铛 + 扫描动画（覆盖以上任意状态） |

「超时 / 还有」的时长按分钟、小时、天自动换算；任务名过长会截断。展开后的列表逾期在前、今天剩余在后，每条标注「超时 2 小时」这类精确时长。

> **逾期口径**：胶囊与展开列表按**精确时刻**判定（今天 10:00 已过点即算逾期），
> 侧边栏「已逾期」视图按**天**判定（今天 00:00 之前），所以胶囊的逾期项数可能多于侧边栏。

### 交互

- **点击药丸**展开为卡片（药丸↔卡片带形状补间动画），可用钉子图标切换置顶、箭头收起。
- **拖动**：按住药丸（或卡片标题区）即可拖到任意位置，位置会被记住；拖动范围限制在屏幕工作区内，位移不足 3 像素按点击处理（不会误拖）。
- **无操作自动收回**：展开后 6 秒内没有真实操作（指针移动、点击、滚轮、按键）就切回胶囊；指针原地不动产生的重复事件不会延长计时。
- **点击穿透**：窗口是固定尺寸的透明窗口，岛体之外自动忽略鼠标事件，不遮挡桌面点击；指针移入岛体即恢复可交互。
- **提醒联动保持当前形态**，也不会把已关闭的悬浮窗重新拉起：
  - 当前是胶囊：蓝色圆内播放匀速扫描光带 + 匀速旋转弧环，图标切换为铃铛，文字上滑淡入，5 秒后复原；
  - 当前是卡片：显示渐变横幅，5 秒后移除。
- **形态动画全程不透明**，不会透出桌面。
- 主窗口与悬浮窗的按钮提示都是自绘 tooltip（不使用原生 `title`——系统提示框在深色下是白底白边）。

## 新建任务卡片

「新建任务」表单默认隐藏，点击顶部「新建任务」按钮后以**悬浮卡片**形式出现在窗口顶部；点遮罩、右上角关闭或按 `Esc` 收起。

## 外观与主题色

- **外观**：跟随系统 / 浅色 / 深色。选「跟随系统」时 Windows 切换深浅色会实时同步。
- **主题色**：7 种预设（靛蓝 / 紫罗兰 / 青碧 / 翡翠 / 琥珀 / 玫红 / 石墨），每种都带浅色与深色两套派生色，主窗口与灵动岛同步应用。

## 分类管理

侧边栏「按分类」右侧的**管理**按钮或 设置 → 分类管理 均可编辑：支持新增、重命名（直接改输入框）、删除；删除时该分类下的任务自动归入「其他」。

## 开机自启与残留文件

便携版每次运行会自解压到 `%TEMP%`，因此：

- **开启自启**：程序复制一份到固定目录 `%APPDATA%\SmartTodoDesktop\智能待办.exe`，并用注册表 `HKCU\...\Run` 指向该副本，同时提示这份副本的存在。
- **取消自启**：删除注册表项，并**自动删除固定目录下的副本**，避免残留（若被占用删除失败会提示手动删除）。

## 数据存储

- `%APPDATA%\smart-todo-desktop\todo-data.json` —— 任务与设置（含退出操作选择、灵动岛位置）
- `%APPDATA%\smart-todo-desktop\window.json` —— 主窗口位置与大小
- 载入时会做一次**设置归一化**：历史版本遗留字段会被剔除并按当前字段表回写，数据文件不会越积越脏。

## 系统托盘

- **单击 / 双击**托盘图标打开主窗口。
- 右键菜单：打开主界面 · 新建任务 · 显示全部任务 · 悬浮窗开关 · 开机自动启动 · 退出。

## 实现要点

- **退出操作**：主进程捕获窗口 `close`，按 `closeAction` 执行；选「彻底退出」时先置 `isQuitting` 再延后 `app.quit()`（在 close 处理器内同步退出会让退出序列卡住）。
- **悬浮窗尺寸**：窗口固定 300×456，药丸↔卡片只改 CSS 类做 `width/height/border-radius` 过渡。`resizable:false` 的窗口在 Windows 上无法用 `setSize` 改变大小，固定尺寸才可靠。
- **悬浮窗拖动**：位置完全在主进程内计算——按下时记录窗口坐标与光标坐标（`getPosition` + `getCursorScreenPoint`），随后每 16ms 采样光标，按「起点 + 总位移」设置位置。不使用增量累加（`setPosition` 会取整，累加会持续累积误差），也不使用渲染进程的事件坐标（与窗口坐标系可能不一致）。
- **跟随系统深浅色**：由主进程 `nativeTheme.on('updated')` 推送给两个窗口；渲染进程的 `matchMedia` change 事件在 Electron 中不触发，因此不作依赖。
- **开机自启**：便携版解压到 `%TEMP%` 后该路径重启即失效，故复制固定副本再用注册表指向它。
- **数据同步**：主窗口保存后由主进程向悬浮窗推送 `data-changed`，胶囊与列表随之刷新。
- **单实例**：`app.requestSingleInstanceLock()`，重复启动聚焦已有窗口。
- **安全隔离**：`contextIsolation: true` + `nodeIntegration: false`，渲染进程仅通过 `preload.js` 暴露的白名单 API 通信。

## 项目结构

```
ToDoDesktopApp/
├── 智能待办-便携版.exe   # 免安装便携版（构建产物，不入库）
├── main.js               # 主进程：窗口 / 悬浮窗（状态·拖动·点击穿透）/ 托盘 / 退出操作 / 开机自启
├── preload.js            # 安全桥接 API（白名单）
├── renderer/
│   ├── index.html        # 主界面
│   ├── app.js            # 主界面逻辑（任务、视图、设置、提醒调度）
│   ├── styles.css        # 主界面样式（明暗主题、主题色、自绘 tooltip）
│   ├── float.html        # 灵动岛悬浮窗
│   ├── float.js          # 悬浮窗逻辑（状态机、形态切换、提醒联动）
│   └── float.css         # 悬浮窗样式（统一动效 token、状态配色）
├── assets/icon.png       # 应用 / 托盘图标
├── package.json
└── dist/                 # 打包产物
```
