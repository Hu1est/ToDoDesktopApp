# 智能待办 · 桌面级待办事项应用

一款**免安装**的桌面级待办事项应用：**灵动岛悬浮窗**、**系统托盘后台常驻**、**按提醒风格自动安排提醒频率**。

> 本仓库为**源码仓库**（不含 66MB 的便携 exe，构建产物已在 `.gitignore` 中排除）。
> 想直接使用，请按下文自行构建，或从本项目的 Releases 下载。

## 快速开始

### 运行开发版

```bash
npm install
npm start
```

### 打包免安装便携版

```bash
npm run dist
# 产物：dist/智能待办-便携版-1.0.0.exe（单文件，解压即用，绿色免安装）
```

打包完成后双击该 exe 即可运行：

- 屏幕右下角出现**灵动岛悬浮窗**（默认开启）
- 系统托盘出现应用图标，关闭窗口的行为由「设置 → 退出操作」决定
- 任务到期时以**应用内弹窗 + 灵动岛**提醒（不含系统级通知）
- 支持**开机自启**

> 若下载 Electron 或打包组件失败，仓库内 `.npmrc` 已配置国内镜像；
> 打包时若因代码签名组件下载超时，可设 `CSC_IDENTITY_AUTO_DISCOVERY=false` 跳过签名。
>
> 若仓库位于 OneDrive 等同步目录，打包解压阶段可能因文件被占用而失败，
> 此时把输出目录指到同步目录之外即可：
>
> ```bash
> npm run dist -- --config.directories.output=D:\todo-dist
> ```

## 提醒风格

侧边栏顶部的「提醒风格」卡片点击后进入**专属覆盖界面**（不与其他设置混在一起）。
界面用生活化语言描述每种风格，并用时间线直观展示"会在什么时候提醒你"：

| 风格 | 适用心态 | 提醒次数 | 提醒时间点（相对截止） |
|------|---------|---------|----------------------|
| 拖延者 · 需要被催 | 我总拖着不动，请多提醒我几次 | 4 次 | 3 天前 / 1 天前 / 12 小时前 / 2 小时前 |
| 忙碌者 · 别烦我 | 我很忙，只在关键节点提醒我 | 2 次 | 1 天前 / 2 小时前 |
| 组织者 · 心里有数 | 我自己会安排，提醒一次就够 | 1 次 | 6 小时前 |
| 完美主义者 · 不能出错 | 我要提前很久就收到分阶段提醒 | 5 次 | 7 天前 / 3 天前 / 1 天前 / 6 小时前 / 1 小时前 |

进入方式：侧边栏「提醒风格」卡片，或 设置 → 提醒风格 → 更改风格。

## 任务视图的范围

侧边栏五个视图的判定范围（均为「未完成」任务，互不重叠）：

| 视图 | 范围 |
|------|------|
| 全部任务 | 所有任务 |
| 今日到期 | 今天 00:00 ~ 今天 24:00 到期 |
| 即将到期 | 明天 00:00 起，至今天起第 7 天 00:00 之前（**不含今天**） |
| 已逾期 | 截止时间在今天 00:00 之前 |
| 已完成 | 已勾选完成 |

「今日到期」+「即将到期」正好是「今天起的 7 天」，两者不会重复出现同一条任务。
鼠标悬停在侧边栏视图名上会显示该范围提示。

## 退出操作（直接选择）

设置 → **退出操作**，三段式直接选择，**选中即生效，无需保存**：

| 选项 | 点关闭按钮时的行为 |
|------|------------------|
| 每次询问 | 弹出「后台常驻 / 彻底退出 / 取消」选择框 |
| 后台常驻 | 窗口隐藏，程序在系统托盘中继续运行并按时提醒 |
| 彻底退出 | 结束程序进程，不再接收提醒 |

- 选择结果持久化在本地数据文件中，重启后保持。
- 选「每次询问」时，对话框里也会提示可到设置中改为直接执行。

## 设置与未保存提示

- 设置面板会跟踪**「提醒提前量 / 声音提示」**的改动，标题旁显示**「有未保存的更改」**标记。
- 未保存就关闭（点 ×、点遮罩、按 Esc）时会询问：**保存 / 放弃更改 / 取消**。
- 退出操作、主题色、外观、提醒风格、分类管理均为**即时生效**，不参与未保存提醒。

## 灵动岛悬浮窗

- **默认开启**（首次启动即出现在屏幕右下角）；可用操作栏「悬浮窗」按钮或托盘菜单开关，开关状态会被记住。
- **折叠态为药丸胶囊**（类似 iOS 灵动岛），显示最要紧的一条信息：
  有逾期时显示「逾期 N 项」+ 最急任务名；否则显示「今日 N 项」+ 最近一条任务名；
  都为空时显示「暂无待办」。任务名过长会自动截断，保证胶囊内一行显示。
- **点击药丸**即展开为卡片（药丸↔卡片带形状补间动画），展示逾期与今日任务列表；
  可按钉子图标切换置顶，按箭头收起回药丸。
- **可拖动**：按住药丸（或卡片标题区）即可拖到屏幕任意位置，位置会被记住；
  拖动时自动限制在屏幕工作区内，位移小于 3 像素仍按点击处理（不会误拖）。
- **形态动画全程不透明**：岛体底色与提醒强调态都用不透明颜色，动画过程中不会透出桌面。
- **无操作自动收回**：展开后若 6 秒内没有真实操作（指针移动、点击、滚轮、按键），
  会自动切回胶囊形态。指针原地不动产生的重复事件不会延长计时。
- **提醒联动保持当前形态**：收到提醒时**不会强行改变**形态，也不会把已关闭的悬浮窗重新拉起——
  - 当前是胶囊：蓝色圆内播放**线性（匀速）扫描光带 + 匀速旋转弧环**，图标切换为铃铛，
    文字上滑淡入显示提醒标题，5 秒后自动复原；
  - 当前是卡片：显示渐变横幅，5 秒后自动移除。
- **点击穿透**：窗口是固定尺寸的透明窗口，岛体之外的空白区会自动忽略鼠标事件，
  因此不会遮挡桌面点击；指针移入岛体即恢复可交互。
- 按钮提示为自绘 tooltip（不使用原生 `title`——系统提示框在深色模式下是白底白边），主窗口同理。
- 实现要点：窗口尺寸**固定不变**，切换只改 CSS 类并用 `width/height/border-radius` 过渡动画；
  `resizable:false` 的窗口在 Windows 上无法用 `setSize` 改变大小，固定尺寸才是可靠方案。

## 提醒方式（不含系统级通知）

- 提醒以**应用内弹窗（toast）+ 灵动岛提示**呈现，不调用 Windows 系统通知。
- 可在「设置 → 提醒方式」中开关声音提示。

## 无边框窗口

主窗口为 borderless（无系统边框），顶部使用自绘标题栏：

- 左侧显示应用名与版本号（主页左上角不再重复大标题）
- 右侧为最小化 / 最大化（还原）/ 关闭按钮
- 关闭按钮的行为由「设置 → 退出操作」决定

## 新建任务卡片（悬浮）

- 「新建任务」表单**默认隐藏**，点击顶部「新建任务」按钮后以**悬浮卡片**形式出现在窗口顶部。
- 点击卡片外遮罩、右上角关闭按钮或按 `Esc` 均可收起。
- 任务列表始终占满内容区宽度。

## 外观与主题色

- **外观**：设置 → 外观，可选「跟随系统 / 浅色 / 深色」。
  选「跟随系统」时，Windows 切换深/浅色会**实时同步**（由主进程 `nativeTheme` 推送；
  渲染进程的 `matchMedia` change 事件在 Electron 中不触发，因此不作依赖）。
- **主题色**：设置 → 主题色，提供 7 种预设（靛蓝 / 紫罗兰 / 青碧 / 翡翠 / 琥珀 / 玫红 / 石墨）。
  主窗口与灵动岛会同步应用；每种预设都带浅色与深色两套派生色，保证对比度。

## 分类管理

- 侧边栏「按分类」右侧的**管理**按钮，或「设置 → 分类管理」，均可编辑分类。
- 支持**新增**（输入名称后回车或点添加）、**重命名**（直接改输入框）、**删除**。
- 删除分类时，该分类下的任务会自动归入「其他」；分类数据随设置一起持久化。

## 开机自启与残留文件

便携版每次运行会自解压到 `%TEMP%`，因此：

- **开启自启时**：程序复制一份到固定目录 `%APPDATA%\SmartTodoDesktop\智能待办.exe`，
  并通过注册表 `HKCU\...\Run` 指向该固定副本；同时提示可能存在该副本文件。
- **取消自启时**：程序会删除注册表项，并**自动删除固定目录下的副本文件**，
  避免残留（若文件被占用删除失败，会提示手动删除）。

## 数据存储位置

- 数据目录：`%APPDATA%\smart-todo-desktop\`
  - `todo-data.json` —— 任务与设置数据（含退出操作选择、灵动岛位置）
  - `window.json` —— 窗口位置记忆
- 载入时会做一次**设置归一化**：历史版本遗留的字段会被剔除并按当前字段表回写，
  数据文件不会越积越脏。

## 系统托盘使用

- **单击 / 双击**托盘图标：打开主窗口
- **托盘右键菜单**：
  - 打开主界面
  - 新建任务 / 显示全部任务
  - 悬浮窗（开关）
  - 开机自动启动（勾选）
  - 退出

## 系统级能力实现

- **退出操作**：主进程捕获窗口 `close` 事件，按 `closeAction`（每次询问 / 后台常驻 / 彻底退出）执行；
  选择「彻底退出」时先置 `isQuitting` 再延后 `app.quit()`，避免在 close 处理器内同步退出导致退出序列卡住。
- **开机自启（避免 temp 路径）**：便携版每次运行会自解压到 `%TEMP%` 临时目录，
  直接把自启项指向该路径重启即失效。因此把便携 exe 复制一份到固定目录
  `%APPDATA%\SmartTodoDesktop\`，通过注册表 `HKCU\...\Run` 键指向该固定副本。
- **单实例**：`app.requestSingleInstanceLock()`，重复启动聚焦已有窗口
- **数据持久化**：JSON 文件写入用户数据目录，主窗口与悬浮窗共用同一份数据
- **安全隔离**：`contextIsolation: true` + `nodeIntegration: false`，渲染进程仅通过 `preload.js` 暴露的白名单 API 通信
