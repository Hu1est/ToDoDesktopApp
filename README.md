# 智能待办

免安装的 Windows 桌面待办应用：托盘后台常驻，屏幕右下角常驻一个可拖动的悬浮窗，按提醒风格自动安排提醒时间点。

<img src="docs/screenshots/01-main.png" width="820" alt="主界面：侧边栏为提醒风格与视图筛选，主区为统计卡片与任务列表">

## 快速开始

下载 `智能待办-便携版.exe`（Releases，或按下方自行构建）后双击即可运行，无需安装。首次启动会看到：

- 屏幕右下角的悬浮窗，以及系统托盘图标
- 5 条带「示例」标记的示例任务，默认不提醒，说明卡片里可一键清空
- 任务到期时以应用内弹窗和悬浮窗提醒
- 第一次点关闭会询问「后台常驻 / 彻底退出」，选择会被记住

从源码构建（仓库不含 exe）：

```bash
npm install
npm start          # 开发运行
npm test           # 可选：提醒规则单元测试
npm run dist       # 打包：dist/智能待办-便携版-1.0.0.exe
```

## 功能

| 功能 | 说明 |
|------|------|
| 桌面集成 | Windows 原生窗口与系统托盘，无边框自绘标题栏，图标全部为矢量图 |
| 悬浮窗 | 胶囊显示最要紧的一条任务，点击展开列表；可拖到任意位置并记住位置，右键弹出常用操作菜单 |
| 稍后提醒 | 10 分钟 / 1 小时 / 明天，胶囊、卡片横幅、托盘菜单都能操作，任务行上可随时取消 |
| 全局快捷键 | `Ctrl+Alt+N` 从任何位置呼出「新建任务」 |
| 提醒风格 | 拖延者 / 忙碌者 / 组织者 / 完美主义者，决定提醒次数与提醒时间点 |
| 任务视图 | 全部 / 今日到期 / 即将到期 / 已逾期 / 已完成，可按优先级、分类、关键词筛选 |
| DDL 管理 | 截止日期与时间，自动显示倒计时与逾期时长 |
| 分类管理 | 分类可新增、重命名、删除；删除时其下任务归入「其他」 |
| 外观 | 跟随系统 / 浅色 / 深色，7 种主题色，主窗口与悬浮窗同步 |
| 开机自启 | 一键设置，自启副本与数据文件放在同一目录 |
| 数据 | 本地保存、重启不丢，可导出备份 |

## 提醒风格

侧边栏顶部的风格卡片可打开专属界面，用时间线说明每种风格的提醒节点。

| 风格 | 提醒次数 | 提醒时间点（相对截止） |
|------|---------|----------------------|
| 拖延者 · 需要被催 | 10 | 7 天 / 3 天 / 2 天 / 1 天 / 12 小时 / 6 小时 / 3 小时 / 2 小时 / 1 小时 / 30 分钟前 |
| 忙碌者 · 别烦我 | 2 | 1 天前 / 2 小时前 |
| 组织者 · 心里有数 | 1 | 6 小时前 |
| 完美主义者 · 不能出错 | 5 | 7 天 / 3 天 / 1 天 / 6 小时 / 1 小时前 |

同一提醒点只提醒一次；一次错过多个提醒点时，只补发最近的一条，不会连续弹好几条。

折叠态按状态显示不同内容：

| 状态 | 触发条件 | 胶囊显示 |
|------|---------|---------|
| 逾期 | 有已过截止时间的未完成任务（含今天已过点的） | 逾期 N 项 + 最急任务与超时时长 |
| 即将到期 | 最近一条在 2 小时内到期 | 即将到期 + 任务名与剩余时间 |
| 今日到期 | 今天还有未到期任务 | 今日 N 项 + 最近一条的时间 |
| 今日无到期 | 今天没有，但有更晚的任务 | 下一条的日期与任务名 |
| 全部完成 | 有任务且都已完成 | 已全部完成 + 任务总数 |
| 无任务 | 一条任务都没有 | 暂无任务 |
| 提醒中 | 收到提醒后的 5 秒内 | 提醒标题（覆盖以上任意状态） |

交互：

- 点击胶囊展开为卡片，钉子图标切换置顶，箭头收起；展开后 6 秒无操作自动收回。
- 右键胶囊或卡片弹出菜单：打开主界面、新建任务、设置、稍后提醒、取消稍后提醒、窗口置顶、隐藏悬浮窗。
- 按住胶囊或卡片标题区可拖到任意位置，位置会被记住，拖动范围限制在屏幕内。
- 岛体之外的空白区不遮挡桌面点击。

胶囊与展开列表按精确时刻判定逾期（今天 10:00 过点即算），侧边栏「已逾期」视图按天判定（今天 00:00 之前），所以胶囊的逾期项数可能多于侧边栏。

## 设置与数据

- **提醒方式**：任务到期时弹出应用内提示并在悬浮窗显示横幅，不弹 Windows 系统通知；声音提示可在设置中开关。
- **提醒可靠性**：主进程每 30 秒检查一次，窗口隐藏也不受影响；关闭或休眠期间错过的提醒会在下次启动、唤醒或解锁时补发（最多回溯 12 小时）。
- **退出操作**：只在第一次关闭窗口时询问一次，之后按记住的选择执行；「设置 → 退出操作」可随时切换。
- **开机自启**：开启后程序把自身复制一份到数据目录（`%APPDATA%\smart-todo-desktop\智能待办.exe`）并让自启项指向它，关闭自启时删除副本。副本随程序更新，被误删会在下次启动时补回。
- **数据位置**：`%APPDATA%\smart-todo-desktop\todo-data.json`（任务与设置）、`window.json`（窗口位置）。设置里可「打开数据目录」或「导出备份」。

## 打包说明

- 下载 Electron 或打包组件失败：仓库内 `.npmrc` 已配置国内镜像。
- 代码签名组件下载超时：设置 `CSC_IDENTITY_AUTO_DISCOVERY=false`。
- 仓库位于 OneDrive 等同步目录时解压可能被占用而失败，可把输出目录指到同步目录之外：
  `npm run dist -- --config.directories.output=D:\todo-dist`
- 偶发 `Access is denied`（安全软件拦截新写入的文件）：重试一次即可。
